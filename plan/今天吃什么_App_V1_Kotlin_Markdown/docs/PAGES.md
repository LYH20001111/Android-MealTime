## 6. 食材列表

推荐 Tab：

```text
[全部] [临期] [食材] [调料]
```

列表按照临期优先：

```text
⚠ 番茄
2个 · 1天后过期

⚠ 生菜
1把 · 2天后过期

🥔 土豆
3个 · 7天后过期

🧂 生抽
约30% · 2027-04
```

## 7. 库存详情

字段：

- 食材名称
- 数量
- 单位
- 购买日期
- 生产日期
- 过期日期
- 存放位置
- 备注

操作：

`编辑` / `调整数量` / `删除或归档`

## 8. 完成用餐确认页

```text
午餐

番茄炒蛋
  番茄   -2 个
  鸡蛋   -3 个

蒜蓉生菜
  生菜   -1 把
  蒜     -2 瓣

[调整]                  [确认用餐]
```

## 9. 智能推荐页

展示：

- 推荐菜品
- 推荐得分
- 推荐理由
- 当前库存匹配情况
- 临期食材命中情况

示例：

```text
为你推荐

番茄炒蛋              92分

推荐理由：
✓ 番茄还有1天过期
✓ 鸡蛋库存充足
✓ 最近7天没有吃过

[加入今日]
```

## 11. 页面状态

每个关键页面都要设计：

- Loading
- Empty
- Content
- Error

特别是首页要支持：

1. 完全空白的新用户
2. 有菜谱、无三餐计划
3. 已安排三餐
4. 有临期库存
