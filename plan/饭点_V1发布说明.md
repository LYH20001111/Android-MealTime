# 饭点 · V1.0 发布说明

> 发布日期：2026-09-07　|　包名：com.skyanchor.mealtime　|　平台：Android 7.0+（minSdk 24，targetSdk 37）

## 一句话

饭点 V1 是一款本地优先的个人饮食管理 App：管理你的菜谱库，安排今天三餐，记录家里食材库存与保质期，吃完自动扣库存，临期食材优先提醒与推荐——把"今天吃什么"变成 1 分钟内能完成的事。

## V1 功能清单（P0 + P1 全量）

| 模块 | 功能 |
|---|---|
| 首页 | 今日日期、临期食材提醒条（点击直达智能推荐）、早/午/晚三餐卡片（一餐多菜、已完成徽章、防重复完成）、今日备注（按天存储） |
| 菜谱 | 新增/编辑（封面 Photo Picker、分类、标签、难度、时长、食材/调料行、步骤）、搜索、分类/收藏筛选、详情、归档删除、一键加入某餐 |
| 食材库存 | 食材字典（选择或现场创建）、多批次库存、数量/数量级别（少量/适量/充足）、购买/生产/过期日期（日期选择器）、存放位置、临期识别（紧急 0~1 天 / 临期 2~3 天，阈值可配）、手动调整必留流水、耗尽自动归档 |
| 用餐闭环 | 完成用餐确认页（按菜谱配料自动算预计消耗、逐项可改）、单事务扣库存 + 流水 + 用餐记录 + 餐次状态、库存不足不阻塞并如实记录、防重复确认 |
| 智能推荐 | 规则评分（库存匹配×50 + 临期命中×40 + 收藏×10 + 7 天未吃×10 − 3 天重复×30 − 长时长 5）、推荐理由、库存匹配度、随机一道、加入下一餐 |
| 通知 | 每日临期汇总（最多一次）、提前天数可配、Android 13+ 运行时权限、测试通知按钮 |
| 我的 | 历史用餐记录（归档菜谱名可见）、设置、数据导出/恢复（JSON，全量 11 表）、关于 |
| 设计系统 | 低饱和紫渐变 Design Token 全局统一（颜色/字体/间距/圆角），Compose + Material 3 |

## 验收路径（已真机走通）

新增菜谱（番茄×2、鸡蛋×3）→ 录入库存（番茄 4 个明天过期、鸡蛋 8 个）→ 首页午餐加入该菜 → 完成用餐（预计消耗 tomato -2、egg -3，可调整）→ 库存变为 2 个 / 5 个并产生 CONSUME 流水 → 首页出现临期提醒 → 点击进入推荐（该菜谱 40 分置顶：库存充足 + 临期命中 + 今日刚吃过降权）→ 归档菜谱后历史记录仍完整可见。

质量基线：35 个单元测试全绿（数据层 8、菜谱仓库 5、用餐闭环 6、推荐算法 7、临期计算 7、备份往返 2）；debug/release 构建全通过；核心链路（点菜 → 完成用餐 → 库存扣减）已数据库取证验证。

## 已知限制（V1 范围外或留待后续）

- 无账号/云同步/家庭共享（V2 规划）。
- 推荐为规则算法，权重为经验值（V1.5 调参）。
- 步骤无配图；菜谱封面仅一张。
- 已完成餐次的"修改菜品"仍可进入（可加菜，不会再触发扣减）。
- 数据导出/恢复为整包覆盖式，不做增量合并。

## 升级与数据

- V1 未正式分发前允许破坏性数据库迁移（schema v2）；正式发布后须改为增量迁移。
- 建议用户定期使用"设置 → 数据管理 → 导出数据"备份。
