# 背景资源使用说明

## bg_meal_empty.png

用于没有安排早餐/午餐/晚餐时的 Empty State 卡片。

建议：

```text
Card
├── Background: bg_meal_empty
├── Icon/Illustration: Chef Hat
├── Empty Text
└── Primary CTA: 帮我推荐
```

## bg_meal_card.png

用于已安排餐次的轻量卡片背景或外围氛围背景。

## bg_meal_primary_cta.png

用于 Primary CTA 的视觉参考，例如：

- 完成用餐
- 帮我推荐
- 一键安排

若实际 Compose 中使用渐变，优先用 `Brush.linearGradient`，不必加载此 PNG。

## bg_meal_section.png

用于“今日三餐”区域外围的非常淡的背景过渡。
